# Tutorials

Learning-oriented. Take these in order; each one ends with something working in front of you.
They are safe to run: nothing here deploys, and the only files you create are ones you can
delete.

1. **[Get the site running](01-get-the-site-running.md)** - install the one dependency, build
   the data, serve `www/`, and see the console in your browser. About 10 minutes.
2. **[Add your first entry](02-add-your-first-entry.md)** - research a rename, write the YAML,
   wire it into the sidebar, pass the gates, watch the card appear. About 30 minutes.
3. **[Publish your first guide](03-publish-your-first-guide.md)** - write a short guide with a
   cited fact, a labelled judgement, and a working `{{entry:...}}` link. About 30 minutes.

When you are done, work from the [how-to guides](../how-to/) instead - they assume you have
done these.
